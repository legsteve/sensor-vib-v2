description: Démarre le palier courant (lecture, plan, attente d'accord)
---

Démarrage du palier courant. N'écris aucun code dans cette commande.

1. Lis docs/PROGRESS.md : palier courant, statut, prochaine action,
   hypothèses ouvertes, problèmes notés.
2. Lis la fiche docs/paliers/PN.md du palier courant.
3. Lis dans docs/SPEC.md uniquement les sections citées par la fiche.
   Si une section citée n'existe pas ou ne couvre pas le sujet, signale-le.
4. Lis le CLAUDE.md de chaque sous-dossier que le palier touchera.
5. Si le statut du palier précédent n'est pas « validé », arrête-toi et
   dis-le.
6. Propose un plan : fichiers créés ou modifiés, ordre, tests natifs,
   procédure d'essai, et rappel du critère de sortie mot pour mot.
   Liste les hypothèses que le plan fait, marquées SUPPOSÉ.
7. Mets PROGRESS.md à jour : statut « en cours », date du jour.
8. Attends l'accord explicite avant de coder.

$ARGUMENTS
