# P4 — WiFi et vrai serveur

## But
Transmission HTTPS au serveur existant avec le protocole complet,
`boot_nonce` et file d'attente.

## Sections de spec à lire
- Réseau et protocole serveur
- Persistance (file d'attente, si elle y est décrite)
- Interdits et pièges connus (certificat, MQTT)

## Fichiers attendus (proposition, à valider au /palier-debut)
- `src/hal/wifi/` : connexion, HTTPS, arrêt avant sommeil
- `src/logic/` : construction des messages du protocole, file d'attente
- `test/` : tests natifs du protocole et de la file
- `src/app/` : état Transmettre

## Hors périmètre
Horloge et filtre (tout est transmis), heartbeats jour/nuit,
configuration en trois couches, mode service.

## Test
`pio test -e native` vert, puis protocole de test rapide côté serveur.

## Critère de sortie
Protocole réussi et aucun doublon signalé par le serveur. MESURÉ, avec
la référence des logs serveur.
